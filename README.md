# 📊 Mutual Fund Analytics Platform
### Bluestock Fintech Internship Capstone | June 2026 | Shahin Shafi

A full-stack data analytics platform that ingests 10 public Indian mutual fund datasets, processes 107,779 rows through a Python ETL pipeline into a normalised SQLite star schema, and delivers business insights through a Power BI dashboard and Python analytics notebooks.

## ⚙️ How to Run

**1. Clone the repository**
```bash
git clone https://github.com/Shahinshafi1717/mutual-fund-platform.git
cd mutual-fund-platform
```

**2. Install dependencies**
```bash
pip install -r requirements.txt
```

**3. Run the full pipeline**
```bash
python run_pipeline.py
```
This runs ETL → DB load → Analytics in sequence. All outputs go to `data/processed/`.

**4. Open the dashboard**
- Download `dashboard/MutualFund_Dashboard.pbix`
- Open with **Power BI Desktop** (free download from microsoft.com)
- All 4 pages load automatically

## 📈 Key Findings

- **SBI Mutual Fund** leads with ₹12.5L Cr AUM — 19.9% market share
- **SIP inflows grew 169%** from ₹11,517 Cr (Jan 2022) to ₹31,002 Cr (Dec 2025)
- **97.8% of SIP investors** show average gaps exceeding 35 days — high churn risk
- **Small Cap VaR** is 100x higher than Liquid funds (−2.39% vs −0.02% daily)
- **ICICI Pru Midcap** scores highest on composite scorecard (85.1/100)
- **26–35 age group** drives 18% of total investment volume (₹64 Cr)
- **Large Cap funds** have pairwise correlation of 0.85–0.97 — minimal diversification benefit

## 🗄 Database Schema

| Table | Type | Rows | Description |
|---|---|---|---|
| dim_fund | Dimension | 40 | Fund schemes with AMC, category, risk |
| dim_date | Dimension | 1,826 | Full calendar spine 2022–2026 |
| fact_nav | Fact | 64,320 | Daily NAV after holiday forward-fill |
| fact_transactions | Fact | 32,778 | Investor buy/sell/SIP transactions |
| fact_performance | Fact | 40 | Pre-computed risk metrics |
| fact_portfolio | Fact | 322 | Equity holdings with sector weights |
| fact_aum | Fact | 90 | Quarterly AUM by fund house |
| fact_sip_industry | Fact | 48 | Monthly SIP inflows |
| fact_category_inflows | Fact | 144 | Net inflows by category |
| fact_folio_count | Fact | 21 | Quarterly industry folio counts |
| benchmark_indices | Reference | 8,050 | 7 benchmark indices daily values |

## 💡 Business Recommendations

1. **Target 26–35 age group** with Moderate-risk Large Cap Direct plan campaigns
2. **Address SIP discontinuity** — automated SMS/email alerts when gaps exceed 35 days
3. **Promote Direct plans** — 0.6–1.0% lower expense ratio compounds to 15–25% more wealth over 10 years
4. **Diversify Large Cap allocations** — high correlation (0.85–0.97) means minimal diversification benefit
5. **Monitor sector concentration** — Axis Bluechip HHI 0.206 indicates dangerous concentration
